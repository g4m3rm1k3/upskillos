# Neural Net Lab: plan and status

A lab (`#/lab/neural-net-lab`) that teaches deep learning from basic Python: what a network is, every piece of it built by hand first (a layer, ReLU, sigmoid, softmax, the loss, backpropagation, SGD, momentum, Adam), then the same thing in PyTorch, checked to give the same numbers. Each kind of task gets its own part, and in every part the learner tries the trained model on their own input: numbers they type, points they draw, their own handwriting, classes they make up.

Asked for on 2026-10-11: "the handwriting example but with more examples the learner can test with their own handwriting and other data … I want to understand the network, how the relu and adam and stuff, what they do and the softmax … PyTorch is fine if it doesn't abstract too much away". Read this file first when resuming.

## Format

QMaze Lab and CartPole Lab's shape (ordered lessons of blocks, every line of every Python program explained, the Real Python tab), with three things borrowed from the arcade labs and one new tab:

| From | What |
|---|---|
| CartPole Lab, via `src/labs/python-steps/` | The Real Python tab, shared: what each line does, its maths, its arithmetic with the paused program's numbers, its logic in words, the call chain, what it calls, live names |
| A-Arcade Breakdown | **Symbol tables**: every symbol with how to say it, what it means, the variable that holds it |
| A-Arcade Guided | **Predict, then watch**: predict blocks before code runs |
| Q-Arcade | **PyTorch first, then Keras**: each model shown in Keras beside the PyTorch version, saying which part of the loop `fit()` hides |
| New | **Model Studio** tab: stack layers like Keras' `Sequential`, pick data and optimiser, train live in the browser, try your own input, and read the matching PyTorch and Keras code |

Rule: nothing is used before it is built. A layer is written as loops over lists before `nn.Linear`; backpropagation is written by hand before `loss.backward()`, and the two are checked against each other.

## Parts

1. **Predicting a number** (regression). Data and a model; one neuron and its loss; gradient descent; a layer; activations (why ReLU bends a line); backpropagation by hand; training a network; the same in PyTorch (and Keras); real data: fuel economy from a car's weight and horsepower (UCI Auto MPG), predicted for a car you describe.
2. **Yes or no** (binary classification). Sigmoid, binary cross-entropy, the decision boundary; points you draw in two colours; a real medical table (breast cancer, UCI); thresholds, accuracy, precision and recall.
3. **One of several** (multi-class). Softmax and how it makes probabilities, cross-entropy; iris flowers; 8 × 8 handwritten digits; the confusion table.
4. **Your handwriting**. MNIST 28 × 28 in the browser; a drawing pad; making your drawing look like MNIST (centre, scale, thickness); first-layer weights as pictures; your own classes, trained and used.
5. **Training well**. SGD, momentum and Adam side by side on one loss surface; batches and epochs; learning rate; initialisation; overfitting, early stopping, dropout, weight decay.
6. **Pictures properly**. Convolution as a filter you can see; a small CNN on digits; saving, loading and using a model.
