# Data in this folder

`mnist-small.dat`: the first 3,000 training and the first 1,000 test digits of MNIST, gzip-compressed, in the layout described in `../tools/make_mnist_small.py`.

MNIST: Yann LeCun, Corinna Cortes and Christopher J. C. Burges, "The MNIST database of handwritten digits" (1998), licensed CC BY-SA 3.0 (https://creativecommons.org/licenses/by-sa/3.0/). This sample is a subset of it and is shared under the same licence. Downloaded from the mirror `https://ossci-datasets.s3.amazonaws.com/mnist/` (the one torchvision uses).

The CSV files beside the Python programs (`../python/*.csv`) come from the UCI Machine Learning Repository under CC BY 4.0: Auto MPG (Quinlan, 1993), Breast Cancer Wisconsin (Diagnostic) (Wolberg, Street and Mangasarian, 1995), Iris (Fisher, 1936) and Optical Recognition of Handwritten Digits, test set (Alpaydin and Kaynak, 1998).
